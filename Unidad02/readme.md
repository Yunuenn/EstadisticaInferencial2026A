# Descripción del Dataset de Gimnasio

Este conjunto de datos proporciona información detallada sobre las rutinas de ejercicio, características físicas y métricas de rendimiento de los miembros de un gimnasio. Contiene **973 registros** e incluye indicadores como la frecuencia cardíaca, las calorías quemadas y la duración del entrenamiento.

## Variables principales

| Variable | Descripción |
|---|---|
| **Age** | Edad del miembro |
| **Gender** | Género del miembro (Male/Female) |
| **Weight (kg)** | Peso en kilogramos |
| **Height (m)** | Altura en metros |
| **Max_BPM** | Frecuencia cardíaca máxima durante el entrenamiento |
| **Avg_BPM** | Frecuencia cardíaca promedio durante el entrenamiento |
| **Resting_BPM** | Frecuencia cardíaca en reposo antes del entrenamiento |
| **Session_Duration (hours)** | Duración de la sesión de ejercicio en horas |
| **Calories_Burned** | Calorías quemadas durante la sesión |
| **Workout_Type** | Tipo de entrenamiento: Cardio, Strength, Yoga, HIIT, etc. |
| **Fat_Percentage** | Porcentaje de grasa corporal |
| **Water_Intake (liters)** | Consumo de agua en litros |
| **Workout_Frequency (days/week)** | Frecuencia de entrenamiento por semana |
| **Experience_Level** | Nivel de experiencia: 1 = principiante, 2 = intermedio, 3 = experto |
| **BMI** | Índice de masa corporal, calculado a partir del peso y la altura |

## Utilidad del dataset

Este dataset puede utilizarse para analizar:

- Hábitos de ejercicio.
- Relación entre la duración del entrenamiento y las calorías quemadas.
- Diferencias entre tipos de entrenamiento.
- Relación entre experiencia y rendimiento físico.
- Comportamiento de la frecuencia cardíaca durante el ejercicio.
- Relación entre peso, altura y BMI.
- Hábitos de hidratación y frecuencia de entrenamiento.

En general, los datos permiten estudiar **patrones de entrenamiento, rendimiento físico y características de los miembros del gimnasio**.
